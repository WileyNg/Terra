Rhino 7 & 8 · Windows Version —

Terra.

Terrain and landscape tools for Rhino. Sculpt ground, import real sites, grade paths and walls, read cut and fill — free, and built for landscape architects.

Install

Two ways in
Route A — recommended

Package Manager

  1. Open Rhino.
  2. Run _PackageManager.
  3. Search for Terra and click Install.
  4. Restart Rhino.
Route B — manual

Download the RHI

  1. Download the package from Food4Rhino.
  2. Close Rhino.
  3. Double-click the installer.
  4. Reopen Rhino — commands start with Terra_.
